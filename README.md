# URL Shortener

A full-stack URL Shortener built using the MERN stack. It converts long URLs into short, shareable links and redirects users to the original URL.
The application also generates QR code of the shortened link using the react QR component.

## Live Demo
Frontend:
https://url-shortener-frontend-4nr9.onrender.com

## Features

- Shorten long URLs into compact links
- Generate unique short IDs
- Redirect short URLs to the original URL
- Copy generated short URLs
- Generate QR codes for shortened URLs
- URL storage using MongoDB
- REST API based backend
- Responsive frontend
- Deployed using Render

## Tech Stack used

- React

### Backend
